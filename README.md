# Anonimizador

Página de presentación y herramienta web para tapar datos sensibles en imágenes, PDF y texto antes de subirlos a una IA.

- `/` — la página de presentación: qué hace, cómo se usa y cómo comprobar que no envía nada.
- `/herramienta/` — la herramienta. Todo se procesa en el navegador; no hay servidor que reciba archivos.

Reduce el riesgo; revise siempre el resultado antes de compartir.

La herramienta incluye Tesseract.js y pdf.js (Apache-2.0); sus licencias están en `herramienta/vendor/licenses/`.
