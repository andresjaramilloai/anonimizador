# Anonimizador (web)

Tapa datos sensibles en imágenes, PDF y texto antes de subirlos a una IA. Todo se procesa en el navegador; no hay servidor que reciba archivos.

Reduce el riesgo; revisa siempre el resultado antes de compartir.

Incluye Tesseract.js y pdf.js (Apache-2.0); licencias en `vendor/licenses/`.
